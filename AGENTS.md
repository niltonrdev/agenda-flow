# Agent instructions

This repo uses Matt Pocock's Skills for Real Engineers. Align → spec → tickets → implement with TDD. Do not start coding from a vague idea.

## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature>/` (solo local tracker). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
