# A v1 é uma Conversa, não WhatsApp

A metáfora original era “manda no WhatsApp e cai no calendário”. O Dono não tem WhatsApp Business; a Cloud API da Meta exige conta Business, número e review. Na v1 o canal é um chat estilo conversa (texto e áudio). WhatsApp oficial fica para depois, se o corte pessoal funcionar. Cliente não-oficial de WhatsApp pessoal está fora: viola os termos e arrisca o número.
